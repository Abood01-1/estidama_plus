# 🌍 منصة استدامة+ (Estidama Plus)

منصة ويب تفاعلية لحساب وتتبع البصمة الكربونية الشخصية بأسلوب Cyberpunk احترافي، مع نظام لعبة تحفيزي يشجع المستخدمين على تحسين بصمتهم الكربونية.

---

## ✨ المميزات الرئيسية

### 🎮 نظام اللعبة التفاعلي
- **نظام النقاط**: اكسب نقاطاً عند تحسين بصمتك الكربونية
- **6 شارات Cyberpunk**: شارات حصرية مع تأثيرات نيون
- **لوحة المتصدرين**: تنافس مع المستخدمين الآخرين
- **تحديات يومية**: 6 تحديات يومية + تحدٍ أسبوعي
- **نظام المستويات**: ارتقِ من المستوى 1 إلى 10

### 📊 حسابات البصمة الكربونية
- **المواصلات**: سيارة، طيران، مشي
- **الطاقة**: استهلاك الكهرباء والمياه
- **الغذاء**: العادات الغذائية والنباتية
- **معايير علمية**: بناءً على EPA, IPCC, Carbon Trust
- **مقارنات**: مع المتوسط الإماراتي والعالمي

### 🤖 الذكاء الاصطناعي
- **توصيات ذكية**: نصائح مخصصة لتقليل البصمة
- **تحليل البيانات**: فهم نمط حياتك
- **توصيات عربية**: كل النصائح باللغة العربية
- **تخصيص إماراتي**: توصيات خاصة بنمط الحياة في الإمارات

### 🎨 التصميم
- **Cyberpunk Style**: تصميم مستقبلي بألوان Neon
- **Neon Pink (#ff007f)**: اللون الأساسي
- **Electric Cyan (#00ffff)**: اللون الثانوي
- **دعم عربي كامل**: RTL على جميع الواجهات
- **تأثيرات نيون**: توهج خارجي وتأثيرات بصرية

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- pnpm أو npm
- MySQL (اختياري للقاعدة المحلية)

### التثبيت
```bash
# استخرج الملفات
unzip estidama-plus-web-complete.zip
cd estidama-plus-web

# ثبّت المكتبات
pnpm install

# شغّل خادم التطوير
pnpm dev

# افتح المتصفح على
http://localhost:3000
```

📖 لمزيد من التفاصيل، اقرأ [SETUP_GUIDE.md](./SETUP_GUIDE.md)

```
estidama-plus/

│   ├── src/components/    # مكونات UI
│   └── src/hooks/         # React hooks مخصصة
├── server/                 # الخادم (Express + tRPC)
│   ├── routers.ts         # API endpoints
│   ├── gamification.ts    # نظام النقاط والشارات
│   └── recommendations.ts # نظام التوصيات
├── drizzle/               # قاعدة البيانات
│   └── schema.ts          # تعريف الجداول
├── shared/                # الكود المشترك
│   └── carbon-constants.ts # ثوابت الحسابات
└── scripts/               # أدوات مساعدة
    └── seed-badges.mjs    # إضافة الشارات الأولية
```

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 19**: مكتبة واجهات المستخدم
- **Tailwind CSS 4**: أنماط CSS حديثة
- **TypeScript**: لغة برمجة آمنة
- **Recharts**: رسوم بيانية تفاعلية
- **shadcn/ui**: مكونات UI احترافية

### Backend
- **Express**: خادم ويب
- **tRPC**: API آمن بـ TypeScript
- **Node.js**: بيئة التشغيل

### Database
- **MySQL**: قاعدة البيانات
- **Drizzle ORM**: مدير قاعدة البيانات

### Build & Tools
- **Vite**: أداة البناء السريعة
- **Vitest**: اختبارات الوحدة
- **pnpm**: مدير الحزم

## 📊 نظام النقاط والشارات

### الشارات الستة:
1. **🌱 البداية الخضراء** - احصل على 100 نقطة
2. **⚔️ محارب الاستدامة** - احصل على 500 نقطة
3. **🌍 بطل الكوكب** - احصل على 1000 نقطة
4. **📉 مقلل الانبعاثات** - قلل بصمتك بـ 20%
5. **💨 الرياح الخضراء** - أكمل 7 تحديات متتالية
6. **👑 سفير الاستدامة** - وصل إلى المستوى 10

### نظام المستويات:
- **المستوى 1**: 0-500 نقطة
- **المستوى 2**: 500-1000 نقطة
- **المستوى 3**: 1000-1500 نقطة
- ... وهكذا حتى المستوى 10
